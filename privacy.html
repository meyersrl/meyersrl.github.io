Privacy Policy

Last updated: 16 September 2026

This policy covers a personal, self-hosted installation of Home Assistant running on a Raspberry Pi in a single private household. The application has one user: the owner of that home. It is not a service offered to other people.

What Google user data is accessed

With the explicit consent of the account owner, this application uses the Google Smart Device Management API to access:

  • Thermostat status and settings, such as temperature, humidity, mode, and fan state
  • Camera and doorbell live streams and still images
  • Device events, such as motion detected, person detected, and doorbell pressed
  • Basic device information, such as device name, type, and room assignment

How that data is used

Solely to display and control the devices belonging to the account owner within their own home, and to run household automations, for example showing the doorbell camera on a television when someone rings.

How that data is stored

All data remains on the Raspberry Pi inside the home. Device history is kept in a local database on that device. Encrypted backups of that system are stored in the private Google Drive account of the owner. Access credentials are stored locally on the same device.

How that data is shared

It is not shared. No Google user data is transferred to any third party, sold, used for advertising, or used to train any model. No analytics or tracking services receive it. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local history is retained for a limited period and then automatically purged. All stored data can be deleted at any time by removing the integration from Home Assistant, which also deletes the stored credentials. Access can be revoked at any time from the Google Account permissions page.

Data about children

No data is knowingly collected about children, and the application is not directed at children.

Contact

This installation is operated by a private individual. Questions can be raised through the contact email listed on the Google consent screen for this application.
